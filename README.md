# H Labs Ecosystem OS

**The Operating System for Web3 Growth.**

H Labs Ecosystem OS is a comprehensive platform integrating intelligence, traffic, capital, and task execution for the Web3 ecosystem.

## Project Structure

This project is built with React and Vite, using a modern component-based architecture.

```text
/
├── public/                 # Static assets
├── src/                    # Source code
│   ├── components/         # Reusable UI components
│   │   ├── landing/        # Components specific to the landing page
│   │   ├── layout/         # Layout components (Footer, etc.)
│   │   └── visualizations/ # Complex data visualization components
│   ├── constants/          # Static data and translations
│   ├── types/              # TypeScript type definitions
│   ├── App.tsx             # Main application component
│   └── index.tsx           # Entry point
├── index.html              # HTML entry point
└── vite.config.ts          # Vite configuration
```

## Features

- **War Room Intelligence**: Real-time market data and signals.
- **KOL Traffic Matrix**: Influencer analytics and tools.
- **Bounty Hall**: Task execution and earning platform.
- **H-Academy**: Web3 educational resources.
- **H-Fund Portfolio**: Asset management dashboard.

## Tech Stack

- **Framework**: React 18+
- **Build Tool**: Vite
- **Styling**: Tailwind CSS, Lucide React (Icons)
- **Language**: TypeScript

## Getting Started

1.  **Install dependencies**:
    ```bash
    npm install
    ```

2.  **Run development server**:
    ```bash
    npm run dev
    ```

3.  **Build for production**:
    ```bash
    npm run build
    ```
